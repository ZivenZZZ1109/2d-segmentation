# Attribution And Licensing

This repository contains selected general-purpose components refactored from the
maintainer's image-segmentation work. U-Net is an established architecture; the
project does not claim authorship of the underlying method.

The baseline lineage includes the TensorFlow/Keras seafloor segmentation
implementation credited to ycu-iil (2021), associated with
[Terayama et al., DOI: 10.1111/2041-210X.13744](https://doi.org/10.1111/2041-210X.13744).
Its upstream MIT notice is retained in `licenses/UPSTREAM_MIT.txt`. The upstream
source, datasets, pretrained weights, and example photographs are not bundled.

The retained upstream license applies to the relevant upstream material; it does
not by itself establish a blanket license for every new file in this repository.
A repository-wide license for the newly written components has not been assigned.
Third-party dependencies retain their respective licenses.
